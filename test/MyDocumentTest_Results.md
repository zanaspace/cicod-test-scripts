## 4. Deviations (Not Bugs, But Worth a Note)

1. **Login domain field mismatch**: the login page pre-fills the tenant/domain field from the `?tenant=cicodecm` URL query parameter, but the account's actual domain is `cicodecms` (with a trailing "s") per `.env`'s `target3_domain`. Logging in with the pre-filled `cicodecm` value fails with "Invalid Email or Password"; the correct domain (`cicodecms`) must be typed in manually. Worth checking whether the tenant URL param and the account's actual domain have drifted out of sync.
2. **Folder-level actions remain reduced** vs. both the test script and the richer file-level menu: folders only offer Open/Share/View Access/Star — no rename, download, delete, archive, attach-to-ticket, or "get folder link", unchanged from the September 15, 2026 baseline.
3. **File context-menu overflow is not visually obvious**: "Move File", "Remove from star", and "Trash" only exist below a `max-h-[300px]` scroll cutoff with a thin scrollbar as the only affordance — a first-time user opening the menu would very plausibly not discover Delete/Move exist at all without scrolling.

## 5. Suggested Improvements

### A. Fix priority
- None confirmed as defects this session, so no P1/P2 fix list. The one-time "Download File" browser error (Row 15) is worth a closer look even though the backend link itself checked out valid — if the signed URL's expiry window is short (5 minutes observed), consider lengthening it or generating it closer to the actual browser fetch to avoid edge-case races.

### B. Test-script / coverage gaps
- **Test script (`test/MyDocumentTest.md`) is stale relative to the live UI** in several places: it references PIN/rename/download/attach-to-ticket/archive on folders (none exist), a literal drag-and-drop signature builder (the live UI is closer to click-tool-then-click-canvas), and a "Print" action (no such action was found anywhere in the file or version-history menus). Recommend a script refresh once product intent is confirmed with the team.
- **Not exercised this session**: Copy File, Move File (clicked into but not completed), a real folder-upload flow distinct from multi-file upload, Attach to Ticket, and Archive — none of these have any visible entry point in the current My Documents UI for either files or folders, so they may simply not exist yet; worth a product confirmation rather than continued UAT search.
- **Historic Files, Departments, Collaborations, General/Application/ECMS/WFM Documents** sub-sections visible in the sidebar were not exercised — out of scope for `MyDocumentTest.md` but worth their own dedicated test pass if not already covered elsewhere.
- Recent/Starred/Trash sidebar destinations were not re-verified in this session; they already have dedicated test files (`RecentDocumentTest.md`, `StarredDocumentTest.md`, `TrashDocumentTest.md`) from September 16, 2026.
