Confirmed Defects
  1. P0 — Department linking cannot be completed. "Generate Folder Path" (mandatory when linking a workflow to a Department) opens an embedded Gov Drive panel that gets stuck on "Session Expired" — reproduced 3/3 times across two different queues, one brand-new and one long-established. The Folder Path field is disabled with no manual-entry workaround, so a workflow can never be saved while linked to a department.
  2. Role-access grid renders empty. Summary cards show 5 total/5 active/0 suspended roles, but the table body has zero rows — reproduced after a full reload. No role can be selected to grant workflow access.
  3. Queue/Queue Type/Status tabs are not reload-safe. Direct navigation or refresh on ?r=workflows/queue returns a generic "Oops! Something went wrong" page; these views only work via in-app client-side tab switches.
  4. Row action menu shows the wrong content on all three tabs. Clicking a row's action button on Queue, Queue Type, or Status opens the workflow-level "View/Unsuspend/Update workflow" menu instead of a row-specific action, blocking Update flows and everything downstream of them in the script.
